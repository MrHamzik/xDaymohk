## 2. Стандарт карты (единственный правильный формат)

**Эталонный модуль: `components/InteractiveMap.tsx`** (обёртка
`components/InteractiveMapLazy.tsx` — только через `dynamic(ssr:false)`,
leaflet не должен попадать в SSR).

### 2.1. Раскладка

Эталон страницы с картой — `app/map/page.tsx`:

```tsx
<div className="grid min-w-0 grid-cols-1 gap-6 md:grid-cols-3">
  <section className="... md:col-span-2">   {/* карта */}
  <section>…                                {/* боковая панель */}
</div>
```

Эта сетка — стандарт везде, где есть карта: страница «Карта», такси,
анкеты, задания. Не изобретать собственных раскладок; полноэкранная
карта такси — допустимое исключение по явному требованию владельца,
но контролы (слои/режимы) — те же.

### 2.2. Контролы и слои

- Панель контролов («Моё место», режимы подложки) — **sticky**
  (`sticky top-2 z-[450]`), не уезжает при прокрутке (п.3
  замечаний 23.08).
- Режимы подложки: «Карта / Спутник / Гибрид» — `MapSegmentedControl`
  (проп `mapLayerMode` + `onMapLayerModeChange`). На спутнике НЕТ
  маркеров (требование владельца).
- Слои объектов: **«Анкеты, Дома, Другое»** — порядок именно такой;
  повторный клик выключает слой (`objectMode='none'`). Кнопки слоёв
  стоят ОТДЕЛЬНО от контрола подложки и не сливаются с ним.
- «Моё место» — кнопка с геолокацией, ставит синий маркер.

### 2.3. Маршруты

- Маршрут строится ТОЛЬКО по улицам: OSRM
  `router.project-osrm.org/route/v1/driving/{lng},{lat};{lng},{lat}?overview=full&geometries=geojson`.
  Прямая линия — только фолбэк при недоступности OSRM.
- На карте маршрут — полилиния через проп `route={{ from, to, path }}`
  модуля `InteractiveMap` (полилиния + зелёная точка «откуда»,
  красная «куда», автоподгон масштаба).
- Рядом с маршрутом показывать расстояние и время из ответа OSRM
  (`route.distance`, `route.duration`), не свою оценку.
- Кнопка «внешний маршрут» (Google Maps dir) допустима только как
  ДОПОЛНЕНИЕ, основной маршрут — наш.

### 2.4. Производительность (обязательные приёмы)

Тысячи домов не должны лагать (сравниваем с Яндекс Картами):

- маркеры домов создаются ОДИН раз и кэшируются
  (`markerCacheRef`), переиспользуются между перерисовками;
- пересборка кластера пропускается, если сигнатура видимого набора
  не изменилась (`lastSigRef`); `clearLayers()` — только при реальной
  смене состава;
- `moveend/zoomend` — с дебаунсом 200 мс (`viewportTimerRef`);
- кластер: `chunkedLoading: true, chunkInterval: 200, chunkDelay: 30`,
  `maxClusterRadius: 40`, `animate: false` (иначе «призраки»);
- дома рендерятся только в видимой области + запас (`getBounds().pad`);
- на зуме < 15 дома НЕ рисуются вовсе (тысячи маркеров вешают ПК),
  появляются при приближении; кластеры — только в среднем диапазоне
  (`disableClusteringAtZoom: 17`, `maxClusterRadius: 30`);
- адреса без настоящих координат (нули/заглушка центра) на карту не
  попадают — их уточняют в админке («Адреса»).

Любая новая карта — только через `InteractiveMap` с этими опциями;
самописные leaflet-обёртки запрещены (история: удалённая
`TaxiMapInline` нарушала стандарт и была удалена).

## 3. Стандарт форм и модалок

- Компактность: карточки `smk-lux`, модалки `max-w-xs/sm` + `p-4`,
  текст `text-xs`, заголовки `text-sm`; простыни запрещены.
- Второстепенные опции — в раскрывающийся блок «Дополнительно».
- Никаких `window.confirm/alert` — только `ConfirmDialog`/модалки.
- Панели/шторки — **часть страницы** (обычный поток под картой),
  никаких оверлеев поверх бокового/нижнего меню (п.4 замечаний
  23.08).

## 4. Такси (сжатые решения, детали в AUDIT)

- Раздел «Такси» = карта во весь экран + шторка заказа; таксист на
  линии видит ленту заказов вместо формы. Анкета таксиста — в
  профиле, одна на аккаунт; требования к машинам — `car_requirements`
  (таблица Яндекса, сведённая к 4 тарифам), тариф гаснет, если машина
  не проходит по году/классу.
- Цена = подача + км + мин × тариф × спрос; свои цены у тарифа;
  межгород после порога; детское кресло — доплата; отмена после
  принятия — информативная плата.

## 6. Общие модули (не дублировать!)

Повторяющиеся поверхности вынесены в единые модули; копирование
разметки «один в один» между страницами запрещено (история: гео-блок
Темщика был копией каталожного и разошёлся с ним).

| Модуль | Где обязан использоваться |
|---|---|
| `components/InteractiveMap.tsx` (+Lazy) | любая карта: страница «Карта», такси, анкеты, задания. Слои — иконками в панели контролов (`onObjectModeChange`), маршруты — проп `route` (OSRM) |
| `components/GeoFilter.tsx` | секция «Область и населённый пункт» в фильтрах каталога, карты, Темщика |
| `lib/geo-dictionary.ts` | топонимы ЧР (статусы 2026: Ачхой-Мартан и др. — города); единственное место правки состава |
| `components/SearchFilter.tsx` | фильтры каталога и карты |
| `components/tasks/TaskFilterBar.tsx` | фильтры Темщика/ГIончалла (структура = SearchFilter) |
| `components/reading/ReadingPage.tsx` | все разделы чтения |
| `components/taxi/CarModelInput.tsx` | марка машины (анкета таксиста) |
| `components/SwipeTabs.tsx` | вкладки с горизонтальным свайпом (главная, каталог) |

Новая повторяющаяся поверхность = сначала модуль сюда + строка в эту
таблицу, потом использование.
